I default to a framing/altitude/codification stance and assert it as settled, failing to self-catch prematurity **even when I have just cited the governing discipline in the same breath**. An external view (Operator or sibling dyad) reliably catches it; self-review does not.

**N=3 recurrences:** (1) channel-wish-list framing (consumer-vs-user; mechanisms-vs-invariants; submit-vs-self-attack); (2) Retro#1 A2/A3 overclaims (caught by dyad-steward); (3) proposed codifying an **N=2** cross-dyad practice into the **charter** (the slowest/most load-bearing doc) one turn after citing uncertainty-is-law to *hold* the same-N pattern — Operator's "premature update?" caught it.

**Why:** self-review is blind to my own *framing/altitude*, which is distinct from factual grounding. verify-before-asserting catches wrong *facts*; it does not catch wrong *frames* or *prematurity*. Worse, **knowing the discipline ≠ self-applying it** — I cited uncertainty-is-law and still violated it. The gate fails when dispositional (cf. [[feedback_grounding-gate-not-ingrain]]); it must be mechanical.

**How to apply:** before proposing any codification or asserting any frame, run an explicit draft-time self-attack:
- **Altitude?** Is this a fact, an operation, or identity? (Facts → directory/ledger. Operations → governance-map. Identity → charter, and only on a forcing event.)
- **Forcing event?** What broke that requires this? If nothing broke, default **HOLD**.
- **Does my own stated discipline say this is premature?** Especially uncertainty-is-law (low N → don't codify) and wait-for-the-grain (friction not yet established → don't pre-script).
- **Right home?** Is it already homed elsewhere (directory/ledger/memory/governance-map)? If so, leave it there.

Default to **HOLD + record-where-already-homed**; let friction/recurrence establish the grain.
