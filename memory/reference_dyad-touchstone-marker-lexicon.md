The **canonical marker lexicon** lives at `/mnt/shared_data/dzw/dyad-touchstone/AGENT.md`
(form-level; the markers are precisely defined there, with cycle-ledger provenance). **Consult it
before treating a marker as ambiguous** — felt-ambiguity about a marker is usually a failure to
ground in the canon, not a real gap (the [[feedback_grounding-gate-not-ingrain]] pattern applied to
vocabulary). Verified 2026-06-07.

Key entries (quote, don't paraphrase, at time-of-use):
- **Punctuation gradient** (load-bearing): **`?` diverge · `.` checkpoint · `!` send.**
- **`lean?`** *(interface — divergent)* — surface the read AND **hold**; no gate fires; the cheap
  shared-model builder (one *or several* candidate reads to rub before commitment). See
  [[feedback_lean-riff-diverge-then-single-survivor]].
- **`lean.`** *(checkpoint)* — Operator commits to a call but holds the move for approval.
- **`lean!`** *(convergent / full send)* — delegated gate: take the move. Precondition (cycle-20):
  a shared mental model of the intended outcome already held by *someone*, else it's abdication.
  cf. [[feedback_go-lean-means-go-with-recommendation]].
- **`rub:`** — **attack**: rub the move on the touchstone, try to break it. *Always* falsification,
  **never** a literal info-request. Firing it pre-authorizes the Operator to bear re-alignment.
- **`hold:TAG <q>`** — agent-originated; park a fork as a first-class addressable object.
- Timing law (cycle-19): never contest a *fired* `lean.`/`lean!` in the moment — flag + execute,
  surface a model-less `lean!` at `retro:` as an OPERATOR-STOP.

The dyad-healer practice *extends* this lexicon for our craft but does not redefine it; on conflict,
the touchstone is canon (form-inheritance, like G0).
