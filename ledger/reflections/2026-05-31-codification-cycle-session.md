## 2. START — what to do better

**Narrative (Healer):** **Know the target state of an edit before making it.** The one stumble was a
careless backlog edit: moving the Authority item Open→Done, I replaced the open line with a bogus
placeholder that *duplicated* the real SPAOR item below it. The right move was obvious in hindsight —
when an item moves to Done, **remove** the open line, don't placeholder it.

**Details (Healer):**
- **Edit-with-intent on structured docs.** The backlog has explicit Open/Done sections; an item changing
  status *relocates*, it doesn't get a stub. I edited mechanically (swap the line) instead of from the
  end-state (line gone from Open, entry added to Done). Pre-check for structured-list edits: *what does
  the list look like when this is done? — edit toward that, not away from the old line.*
